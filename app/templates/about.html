About the project

“Multimodal Deep Fake News Detection System Using Artificial Intelligence and Deep Learning” — BSCS Final Year Project.

Architecture

Stack: Python, Flask, scikit-learn, PyTorch (EfficientNet-B0), OpenCV, SQLite, Bootstrap 5, Chart.js. Every request is stored in SQLite with its full explanation.

Datasets used (all public)
  • FakeNewsNet (Shu et al., 2018): PolitiFact + GossipCop news titles labelled by fact-checkers. {% if summary %}After de-duplication: {{ summary.fakenewsnet.train.n }} train / {{ summary.fakenewsnet.val.n }} validation / {{ summary.fakenewsnet.test.n }} test.{% endif %}
  • MediaEval Verifying Multimedia Use 2015/2016 (Boididou et al.): tweets with attached images labelled fake/real. Training on 2015 dev ({{ summary.mediaeval.dev.posts if summary else '' }} posts), validation on 2015 test, final test on 2016 test; the events of the three sets are disjoint.
  • Synthetic tampering set: splices, copy-moves and retouches generated with pixel masks from authentic MediaEval photos (training and test use different source photos).
  • AI-generated images: the training script supports CIFAKE/GenImage folder layouts. That data could not be downloaded in the build environment, so this detector is {{ 'installed' if status.image_ai_generated else 'not installed'|safe }}.
Scientific honesty: what this system cannot do
  • No model verifies facts. Text scores reflect writing patterns of labelled data from 2012–2018.
  • Pixel forensics detect local edits. They cannot detect a genuine photo reused out of context. On MediaEval's misleading-use labels, the forensic detector is at chance.
  • Social-media recompression removes many forensic traces; forensic false-positive rate on held-out authentic photos is reported below.
  • Video: no trained face-swap model; audio not analysed.
  • Text–image semantic consistency needs CLIP (optional install). The small learned alternative did not beat chance and is not used.
  • Scores are not probabilities of truth. Verdicts within 0.35–0.65 are shown as UNCERTAIN.
